# 示例

两段**自己题目的样片**（`fold_C`、`pigeon_B`，两套外观各一段），两段**学习用的复刻**（各对应一套外观），一张货架图。

这里的东西是"别人怎么做过一次"，不是零件库。文案不同，屏上的东西就不同，代码也不同：新片的每一镜按自己的分镜表现写，不要把这里的珠子、细胞、数轴、骰子搬过去。能带走的是做法（一张分镜表怎么变成画面、哪些东西画在底层、推拉镜头怎么插值、怎么截图自查），不是画面。

`fold_C/`：《折叠》的开头（序 + 第一章），C 夜曲，33 秒，九镜。讲的是血红蛋白错一颗氨基酸怎么把红细胞变成镰刀。
先写的分镜表（`storyboard.md`），再照着做的 `film.js`；`gen_blob.py` 算出"折好的一团"里每颗珠子的位置（`layout.js`）。
可以看的做法：一个世界一台摄影机（血管 → 细胞 → 一串珠子，对数缩放的推拉）；有体积的红细胞画在底层不吃辉光；有光泽的珠子；
珠串卷成一团；一团的凹口卡住另一团鼓出来的珠子；细胞里的小球排成杆把细胞顶弯；提问和结论那两镜什么都不加。
`fold_old_vs_new.jpg` 是同一段内容的两版对照：上排是这个 skill 早先做的（主体是一串星点连成的折线），下排是重做的。为什么差这么多，见 `references/visualization.md` 第〇节和第七节。

`pigeon_B/`：《鸽子的迷信》的开头，B 寓言，33 秒，七句字幕、六个镜头。讲的是斯金纳 1948 年的实验。
这 33 秒只讲一件事：食物按时间来，可它掉下来时鸽子碰巧在转圈，于是鸽子接着转。规则卡、八只鸽子、幸运袜都留给后面——塞进来反而抽象。
可以看的做法：计时器按真实时间走两圈（第 15、30 秒各掉一次食物）；鸽子这 30 秒在干什么写成一张关键帧表；
六个镜头六种景别（全景、特写、中景、近景、慢推、前后景）；两段没有字幕的纯画面；字幕底下压一层暗色，近景时东西不抢字。

下面两段是复刻。做法是：从参考片量出时间点、位置、字号、颜色，用本引擎重画，再和原片同一时刻的帧并排比，改到观感对得上。
它们的用处是当范例翻（"这种装置怎么写"），以及证明这套引擎和规格做得出这种片子。

| 目录 | 世界 | 复刻的是 | 可以看的做法 |
|---|---|---|---|
| `stim_B/` | B 寓言 | 《超常刺激》0–12.5s | 三层视差的插画场景；用色块拼的角色（走、扑、卧）；按参考帧量出来的机位曲线；压暗进片名 |
| `info_C/` | C 夜曲 | 《信息论·惊奇之学》0–47s | 逐字打出的大字 + 空位光标；滚动的候选字；刻度上的光点；"留一个点"接到片名；点阵聚成字；数轴；全部由事件表合成的声音 |
| `kit_gallery/` | — | 不是片子，把 `vk-kit.js` 里的件各演一遍 | 每个件的最小调用 |
| `fold_C/` | C 夜曲 | 不是复刻，自己的题目 | 见上 |
| `pigeon_B/` | B 寓言 | 不是复刻，自己的题目 | 见上 |

`look_*.jpg` 是各自的拼图。`fold_old_vs_new.jpg` 是《折叠》两版对照。

```bash
python ../engine/render.py stim_B --serve         # 预览
python ../engine/render.py info_C --sheet 16       # 拼图
python ../engine/render.py info_C && python ../engine/render.py info_C --events && python ../engine/audio.py info_C
```

## 说明

- `stim_B`、`info_C` 的字幕文字、片名、画面设计来自参考片，版权属于各自的作者；这两段只做了开头几十秒，用于学习和对照，
  不是成片，也不该当作自己的作品发布。做自己的片子用 `scripts/new_film.py` 建一个空骨架，照自己的分镜表现写。
- 不带水印和署名（参考片角上有作者水印，这里没有复刻）。
- 没对上的地方：蛎鹬和海滩的插画细节是按观感重画的，不是逐像素一致；
  B 的配乐是现成曲子，这里没有带；C 的声音是按事件重新合成的，音色和原片不同。
