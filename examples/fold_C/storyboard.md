# 《折叠》序 + 01 形 · 分镜表（33 秒）

**一句话论点**：一串珠子怎么折，决定它是什么；所以错一颗，能改掉一个细胞的形状。

**全片的形象**：一串珠子，和它折成的那一团。观众生活里的锚：血、珠串、"黏住""卡进去"。

**一个世界，一台摄影机**：血管里的红细胞 → 细胞里的血红蛋白 → 一串珠子。镜头只做推近和拉远，没有换场。

**同一个画面**：第 3 镜和第 8 镜是同一个细胞弯成同一把镰刀——第一次是结果，第二次是原因。

**颜色**：冰蓝 = 正常的珠子；玫红 = 错的那颗和它造成的一切；暖红 = 氧气；深红 = 血。
