# 四条参考片的拆解

样本：抖音 #vibe知识大赏 里四条"代码直出"的知识短片。数字都是量出来的（逐帧差分、每秒 OCR、取色、librosa），
下载版是 1024×576 / 30fps，下面的像素值已换算到 1920×1080。

| 代号 | 片名 | 时长 | 作者 | 世界 |
|---|---|---|---|---|
| luck | 运气的形状 DE FORMA FORTUNAE | 130s | 片内有作者水印 | A 鎏金暗场 |
| stim | 超常刺激 SUPERNORMAL STIMULI | 185s | 片内有作者水印 | B 寓言 |
| info | 信息论 · 惊奇之学 | 300s | 片内无署名 | C 夜曲 |
| loop | 自指 · 我是个怪圈 | 334s | 片内无署名 | C 夜曲 |

## 一、四条片都遵守的事（这才是"风格"）

1. **没有人声。** 四条片语音识别都是 0 段。旁白就是底部字幕，观众是在"读"一条片子。
   所以文案量只有口播稿的一半（每分钟 140–240 字），每句话都要短到一眼读完。
2. **先演，后命名。** 片名卡从不在第一秒出现：先用 6–24 秒演一个小东西（骰子落地 / 鸟爬上假蛋 /
   填空题 / 一句数自己字数的话），让观众先"遇到"这个概念，再闪一下亮出片名。
3. **一句字幕，一个屏上动作。** 字幕说"摸上两万五千次"，屏上的计数器就真的数到 25,000，折线真的收敛。
   没有一句话是配着静止画面讲的；也没有一个动作是没有字幕认领的。
4. **图是算出来的，不是画出来的。** 大数定律那条折线是真的随机抽样；布丰投针真的在数压线根数；
   二分法真的问了十次问到 693；塔珀公式真的逐格算出自己。观众能感觉到"这是真的在算"。
5. **全片一个母题，贯穿始终。** luck = 钟形曲线（片名卡下面就是它）；stim = "假蛋" + 仪表「本能读数」；
   info = 一个光点 + 一道填空题；loop = 沿着环跑的光点。新概念出现时，尽量用母题去演，而不是换一套新图形。
6. **结尾回到开头。** 同一个画面再出现一次，但意思变了：骰子回来，身后多了一条曲线；鸟回到自己的蛋上；
   填空题再出现，这次"由你来填"；片名的莫比乌斯环回来，然后画面铺满这条片子自己的源码。
7. **每个事实都带出处。** 年份、人名、原著题名（拉丁文 / 法文原题 + 中文译名）、论文作者年份，
   推测性的内容标"示意""一种假说""据说"。片尾有"文献线索 / 参考文献"。这是它看起来"可信"的来源。

另外几条数字层面的共性：

- **16:9 横屏**，1920×1080，片尾自述"一共 10020 帧"（334s × 30）。loop 的源码注释表明内部按 60fps 出、30fps 显示计数。
- **几乎没有硬切。** luck 全片 0 个硬切；info / loop 各只有 5–6 处亮度突变，全部是"章节开头的一帧闪亮"；
  stim 逐帧差分里的十几处跳变都落在"老纪录片"那一段，是故意做的片门抖动，不是换镜头。
  镜头之间靠溶解、推近、元素变形来接。
- **三分之一的时间画面几乎不动**（静止帧占 31–36%）。这不是偷懒：字幕出完之后留 1–2 秒给人读。
- **字幕停留**：A/B 约 3 秒一句，C 约 5–6 秒一句（C 多一行英文）。字幕覆盖全片 58–74% 的时间，其余留给片名、转场和纯画面。

## 二、三套世界对照

| | A 鎏金暗场 | B 寓言 | C 夜曲 |
|---|---|---|---|
| 样本 | luck | stim | info、loop |
| 适合 | 一门学问的历史：一串"年份 + 人 + 问题" | 一个行为/心理机制：动物实验 → 人 | 一个抽象概念：数学、逻辑、信息 |
| 底 | 近黑，暖棕 ↔ 冷蓝随年代切换，漂着失焦的尘埃，四角压暗 | 每场一幅程序画的扁平插画（海滩、沙漠、夜里的书桌、芦苇荡），暗场只用于片名和"规则卡" | 蓝黑夜空 + 细星点，中央一团深蓝 |
| 主角 | 实物感的小道具：象牙骰子、羊距骨、金币、陶瓮、针、珠子 | 一只鸟（蛎鹬）+ 一颗蛋，全片都拿"假蛋"打比方 | 一个带彗尾的光点，沿细线 / 环运动 |
| 颜色 | 象牙白 `#E8E3D9`、金 `#DDBD74`、朱红 `#D9583C` | 场景色随地点变；字幕暖白 `#FFFAEB`，金 `#EEC672`，"超常"永远是红 `#FC593F` | 白 `#F8F9F8`、金 `#F8D893`（惊奇/真）、冰蓝 `#64E3F6`（已知/可证）、玫红 `#E84B75`（错/噪声/矛盾） |
| 中文字体 | 粗宋（思源宋体 Bold 一类） | 字幕用粗黑体；片名和卡片仍用宋体 | 细宋（Light / Regular），大字距 |
| 西文 | 细衬线大写 + 意大利体原著题名 | 打字机体（新闻稿）、衬线斜体（学名） | 意大利体英文字幕、等宽大写小标 |
| 常驻元素 | 左上"年份里程表 + 地点·人物"；右上"原著题名 + 朱印"；右下水印 | 左上仪表「本能读数」+「对象：×××」；右上水印 | 左上极小章节标"03 余 REDUNDANCY"；无水印 |
| 字幕 | 居中，逐字"由虚变实"，关键词染金、负面词染红，重点句放大 | 居中偏下，粗黑体逐字亮起，关键词染红，规则句整句金色 | 居中，整行淡入，下面一行英文意大利体 |
| 片名卡 | 黑底 + 金色放射线 + 金渐变粗宋 + 母题图形 | 同 A（同一个作者的"厂牌"） | 光点飞过细线，点阵聚成细宋大字 |
| 声音 | 现成配乐，画面卡乐句（112.35 BPM） | 同一首配乐 | 代码合成：低频长音 + 每章一记钟声和弦 + 逐字的"嗒" |
| 画面活跃度 | 忙帧 7% | 忙帧 22%（角色一直在动） | 忙帧 4% |

A 和 B 是同一个作者：同一张金字片名卡、同一个水印、**同一首配乐**（两条片每 10 秒的响度曲线几乎重合）。
也就是说"世界"可以换，"厂牌"（片名卡、署名、配乐、字幕习惯）不换。

## 四、看得见的迭代痕迹

这些片子不是一遍做完的，画面里留着证据：

- **loop 的尾声是后来加长的。** 片尾露出的源码里有 `CODA_EXT`，注释写着"尾声（场景时钟 255–304，电影时钟 285–334）"——
  场景内部的时间和成片时间差了 30 秒，说明尾声写完之后，前面又插进了 30 秒内容（对照结构，多半是 05 章"我"）。
- **按章分文件。** 源码里有 `import x_ch2`：一章一个模块，改一章不动别的章。
- **stim 比配乐长。** 配乐在 160 秒处整首重新开始（起音曲线出现和片头一模一样的图样），而这个点正好卡在"③ 把自己的蛋，放回窝里"——
  片子写长了，配乐不够，于是把重启点对在转折上。
- **同一个版式用两次。** stim 的"银鸥"和"刺鱼"两段是同一个模板换了内容（顶部一行结论 + 左右两个计数器 + 仪表）；
  luck 每一站都是"年份 HUD + 一个图 + 一两句字幕"。做出第一站，后面就是填内容——这是多轮迭代后沉淀下来的骨架。
- **措辞上的谨慎是后补的。** "示意""一种假说""据说""适用于任何自洽、且足以做算术的公理系统"这类小字，
  读起来像是事实核查那一轮加上去的。

## 五、技术栈的证据

- **C（info / loop）是 Python 逐帧画的。** loop 片尾铺的源码可读：`np.zeros((H, W, 3), np.float32)`、`cv2.GaussianBlur`、
  `def scene(t, fi)`、`fr = Frame("ink", …)`、`fr.glow(pp, 6, WHITE, ak * 0.9)` 紧跟 `fr.glow(pp, 18, GOLD, ak * 0.35)`、
  `fr.text(…, "serifl", 24, c2, tracking=24, shadow=0.5)`、`smooth(seg(t, t0 - 0.3, t0 + 0.7))`、`fade(t, 289.6, 298.0, …)`、
  `moebius(fr, 960, 360, 200, t, a_mb)`。也就是：一张浮点帧缓冲，加法混合，高斯模糊做辉光，每一帧是时间 t 的纯函数，
  逻辑画布 1920×1080（960 是水平中心），字体按键名取（serifl / math / mono），颜色是常量（GOLD / WHITE / ICE / AMBER）。
- **A / B 从画面判断不了具体框架**（Canvas、SVG、Remotion 都做得出来）。能确定的是：全部是程序画的矢量和文字，
  没有位图素材；配乐是现成的一首。
- 本 skill 的引擎用浏览器 Canvas 2D 实现了同一个模型（`seek(t)` 纯函数 + 加法辉光 + 字体键 + 颜色常量）。
  复刻只剩寓言和夜曲两段，在 `examples/stim_B`、`examples/info_C`。鎏金暗场不再作为可选外观，也没有对应复刻。
