# 讲解设计：一句文案出来时，画面拿什么让观众懂

这是整个 skill 的核心。色、字、辉光、片名卡都是皮；这种片子好看，是因为**文案说到的每一样东西，屏上都认得出、看得见它在变**。
做片子的人在这里是科普作者兼导演：先把道理弄懂，再替它找一个外行一眼认得的形象，把道理演出来。

先看一个做错的例子，再看四条参考片是怎么做的，然后是方法。

## 〇、配图和讲解的区别

《折叠》（讲蛋白质折叠和 AlphaFold）做过一版，全片的主体是一串星点连成的折线：

- 字幕说"它要折成一个形状，才能干活"——折线卷成一团；
- 字幕说"只换掉第 6 个，形状就变了，这就是镰刀型贫血"——那一团换了个卷法，变成玫红色；
- 字幕说"折法多到写不下"——折线乱抖，旁边一个 10³⁰⁰；
- 字幕说"两亿个"——一根金条长出来。

每一句都"有画面"，而且颜色、字体、节奏都像参考片。可是观众从头到尾没见过蛋白质是个什么东西、它怎么干活、错一个字母到底坏在哪。
这种画面叫配图：把这串星点换给任何一段文案，都同样成立。

讲解是另一回事。同一段内容重做以后，屏上依次是：血管里漂着的红细胞、细胞里的一串珠子、其中一颗变了色、那个红细胞弯成了镰刀、
珠串卷成一团抓住一个氧分子、变色的那颗在表面成了黏点、一团粘一团连成长杆、长杆从里面把细胞顶弯。
每一样东西都叫得出名字、长得像它本身，每一句的动词都在屏上发生了，看完的人能讲出"因为……所以……"。
（完整的对照在第七节，对照图是 `examples/fold_old_vs_new.jpg`。）

### 《信息论 · 惊奇之学》（300 秒）

全片讲了十来个概念，用了十来个具体的小实验。星点只在片名那几秒当过主角。

| 猜不到的才是信息 | 同一个版式换成"那天夜里，窗外下起了＿"，空位里候选字在滚（雨、雪、火、歌、信……），同一把尺子冲到右边 | 亲自试 + 并排比 | 只换了一句话，差别全在猜不猜得到 |
| 我想了一个数，最少要问几次？ | 一条 1–1024 的数轴，一个藏着的金点；问句出现时只多了一个"？" | 提问：不加画面 | — |

| 我们说的话，大部分在意料之中 | 一句地铁广播，每个字底下一根柱子（这个字的惊奇）：三四根高，其余贴地 | 摆到一张图上 | "大部分可预测"= 大部分柱子是矮的 |

## 二、六种画法

一句字幕出来，屏上能做的事只有这六种。分镜表里每一句都要选一种。

**1. 亲自试。** 屏上摆出一个东西，让观众自己起反应；字幕晚半拍出来，说的是观众脑子里刚发生的事。
填空的古诗、乱序的句子、被盖掉一半的广播、数自己字数的句子。用在开头，以及一切"你以为……"的地方。

**2. 照着句子画。** 句子里说到什么，屏上就是什么；句子里的动词，屏上真的做。鸟走向假蛋，甲虫趴上酒瓶，烽火亮起，信飞到图卢兹。
画面没有比句子多说什么，但观众认出了东西，记住了画面。讲故事、举例子、摆事实都用它。人只画背影、剪影、一只手。

**3. 当场做一遍。** 拿一个最小的具体题目，把方法一步一步走完，屏上看得见状态和计数。字幕只用人话说规则，说完常常闭嘴，让过程自己跑。
1 到 1024 猜数、摸两万五千次石子、12 × 12 的程序表、"0 = 0"的编号。讲方法、讲机制、讲"为什么一定是这样"都用它。数是真算的。

**4. 并排比。** 两样东西放进同一个版式，只留一处不同。9 点对 10 点，逼真模型对红棍子，诗对乱码，不下雪对下雪。
也可以是前后两种状态叠在一起。凡是"A 比 B"都用它。

**5. 摆到一张图上。** 把前面已经出场的东西摆进一张坐标图，轴用人话写，重点是图上的一块区域或一条线。"甜 × 油"的空位，"本能 × 刺激"的红区，每个字底下的柱子。
一条片两三次，只在回答"为什么"的时候用，而且一定排在例子后面。

**6. 只上字。** 规则卡、引文卡、命名的大字、公式和它旁边的一句人话、全片最后一句；或者什么都不加，把上一幕停住。

还有两个贯穿全片的动作，不算新画法：**回场**（前面的道具、尺子、开场画面再出现一次）和**合体**（把全片的那个形象和观众生活里的东西放进同一个画面——手机坐在鸟窝里）。

## 三、什么时候画，什么时候不画

能画的尽量画。但四条参考片里，大约每五句就有一句没有配新的画面——那些句子后面的停顿，是观众把刚才看到的东西想明白的时间。

按这句话在做什么来定：

| 这句话在做什么 | 怎么处理 |
|---|---|
| 讲一件事、举一个例子（句子里有东西、有动作） | 照着句子画 |
| 讲一个方法、一个机制、"因为……所以……" | 找一个最小的题目，当场做一遍 |
| 说观众自己的直觉或感受 | 让他亲自试 |
| 比较两样东西 | 并排比 |
| 说一个数量 | 让它数得出来：一格一格、一颗一颗，或者一把全片通用的尺子。不是给数字配一根柱子 |
| 总结"为什么会这样" | 摆到一张图上，用前面出现过的东西摆 |
| 把道理落到"你"身上 | 合体 |
| 提问 | 不加新画面：停住上一幕，或者只留一个问号、一个光标 |
| 起名字、下定义 | 只上字，前面的道具可以围在旁边 |
| 规则、结论、金句 | 只上字（卡片或大字），或者把上一幕停住 |
| 引一句原话 | 引文卡：原文 + 译文 + 出处 |
| 某年、某人、某篇论文 | 一行小字贴在已有的画面上。不为它换场，不画脸 |
| 过渡句（"回到那道题——"） | 不画，让下一幕进场 |
| 该怎么做 | 一步一个具体动作 |

几条容易犯的：

- **刚演过的事，结论句不要再画一遍。** 上一幕已经让观众看懂了，结论句只需要把画面停住。再配一张图表，等于不相信刚才那一幕。
- **没有东西可指的句子不要硬配图。** 态度、判断、过渡，硬配出来的就是光点、连线和抽象图形。
- **一个数能说清的，不画图表。** 要画，就画成数得出来的东西，并且和另一个数放在同一个画面里比。
- **公式不单独解释。** 把它贴在刚演过的例子上，每个符号都对得上屏上的某样东西，旁边一句人话。
- **一个场景撑 2–5 句字幕，每句只改一处。** 不是每句话换一个新版式。

## 四、为什么看得懂，为什么让人惊奇

看得懂，靠的是这几件事：

1. **不用翻译。** 屏上的东西就是句子里说的那个东西。数字、符号、公式是贴在它旁边的小字，不是主体。
2. **先例子，后道理。** 每个抽象的说法出现之前，观众已经看过至少一个具体的例子。名字和公式排在最后。
3. **借观众已有的经验。** 每个难的概念都拴在一件人人经历过的事上：比特拴在"猜数字"上，冗余拴在地铁广播上，停机问题拴在转圈的加载图标上，超常刺激拴在奶茶和短视频上。
4. **量是看得见的。** 多少，是数得出的东西；大小，是长度和高度；比较，在同一个画面里。屏上的数都是算出来的，前后对得上。
5. **一把尺子、几样道具用到底。** 「惊奇」那把尺子量过古诗、烽火、下雪、推荐流；「本能读数」量过蛋和奶茶。观众学会一次，后面都在自己比。
6. **字幕说人话，屏上给证据。** 字幕是一句谁都听得懂的话；p = 1/365 → 8.5 bits、年份、人名、出处，是屏上的小字。
7. **观众先动手。** 开头十秒让他猜、让他数、让他读。

让人惊奇，靠的是这几件事：

- **变脸。** 同一样东西，原来是另一样东西：想删掉的噪声是宇宙的婴儿照，一条公式画出了它自己，撒在地上的针算出了 π。
- **尺度跳变。** 从一个人到一座城的点，从一个转圈到所有程序，从一颗珠子到一个细胞。
- **真算出来的结果。** 计数在跳，曲线在贴过去——观众感觉得到这不是摆拍。
- **回到开头。** 第一秒的画面在最后回来，只改了一处。

## 五、怎么给一个概念找形象

对概念清单里的每一个概念，按顺序问。前面的问题有答案，就不用往后问。

1. **它本身是个东西吗？** 是，就画它本身：鸟、蛋、骰子、信、探测器、DNA、红细胞。用这条片自己的画法（线描、插画、带体积的实物都行），但要一眼认得出。
2. **它是一个过程或方法吗？** 找一个小到能把每一步都画出来的题目，走一遍：1 到 1024、甲 50 比乙 20、12 个程序、一条 5 个符号的公式。
3. **它是一个量、一种程度吗？** 给它一把尺子，用同一把尺子量三样东西。
4. **它是观众脑子里的事吗？** 设计一个五秒钟的小测试，让它当场发生。
5. **它是一条规律吗？** 先各画两三个例子，再把例子摆到一张图上。
6. **都不是**（它是一个判断、一个态度、一句总结）——不画，上字。

找到以后再加三问，把形象做强：

- **观众在生活里哪儿见过它？** 找那个锚。找不到锚的概念，观众记不住。
- **换一个尺度看，是什么样？** 拉近或者拉远一级，原因和结果常常就连上了（一颗珠子 → 一团分子 → 一根长杆 → 一个细胞）。
- **它坏了会怎样？** 让它错一次。东西正常的时候看不出它在干活，坏了才看得出。

### 画得像它本身

找到的形象要画得让人一眼认出来，不能再退回成记号。

- **有体积，有材质。** 红细胞要有厚度，中间凹下去，边上有一道高光；珠子要有光泽，一颗挨一颗穿在线上；氧分子是两个粘在一起的小红球。
  一个圆圈加一个标签"红细胞"，不算画了红细胞。
- **从观众认得的地方进场。** 先给一个人人见过的画面，再推进去找到要讲的东西：从血管里的红细胞推进去，才到那串珠子。
  把一串珠子直接摆在黑底上，观众不知道它在哪、有多大、跟自己有什么关系。
- **记号只当小字用。** 箭头、虚线框、代表"分子"的小圆点、柱子，可以贴在东西旁边做说明，不能自己当主体。
- **不是只能画线。** 《运气的形状》里的骰子、金币、羊距骨是有体积的实物；《超常刺激》整片是插画。
  《惊奇之学》《自指》的主体是字、数轴、表格，那是因为它们的题材本身就是文字和数学——是题材决定的，不是这种片子的规矩。
- **实心的东西画在底层。** 引擎的辉光会把大块的实心颜色冲成一团白：有体积的东西（细胞、身体、场景）画进 `fr.look.under`，发光的线、珠子、字画在上层。

### 每一镜过三问

写不出来的就重做：

- **屏上这是什么？** 用一个日常的词回答（一串珠子、一个红细胞、一条数轴、一句古诗、一张表），而且把字幕遮住、把标签遮住，它还是看得出是这个东西。答案是"一些点""几条线""一个圈""几根柱子"的，不合格——除非它是一件带刻度、带标签、叫得出名字的仪器。
- **它在干什么？** 用一个动词回答，而且就是字幕里的那个动词，或者是它的直接后果。
- **观众因此明白了什么？** 一句话。和上一镜明白的事不一样。

## 六、文案和画面一起写

画不出来，多半是文案的问题：句子里没有东西。参考片的文案，几乎每一句里都有一样屏上看得见的东西和一个动作；
没有的那几句，都是提问、命名和结论，本来就不打算配画面。

所以不是先写完文案再配画面。先给每个概念找到形象（上一节），再把形象里的东西和动作写进句子。

| 画不出来的句子 | 找到形象以后改成 |
|---|---|
| 你身体里的每件事，都由某个形状来做。 | 这串珠子，会自己折成一团，去抓氧气。 |
| 只换掉第 6 个，形状就变了。这就是镰刀型贫血。 | 只换错第 6 颗——圆圆的红细胞，就弯成了镰刀。 |
| 可是怎么折？一条链的折法，多到写不下。 | 每个关节，能朝三个方向拐。两个关节九种，三个二十七种…… |
| 算不出来，只能一个一个去测。 | 把它养成晶体，让 X 光穿过去，从一片斑点里倒推出形状。 |
| 二十多年，分数一直上不去。 | 把答卷叠在标准答案上。二十多年，两条线一直对不上。 |

第二行还顺手改掉了一个错：换掉那个字母以后，这条链的折法几乎没变，变的是表面多了一个黏点。
把道理弄懂是找形象的前提——"形状就变了"这种含糊的话，正是因为没弄懂才写出来的。

### 分镜表

写完再建工程。一句字幕一行：

| # 时间 | 字幕 | 画法 | 屏上是什么，在干什么 | 屏上的小字 | 观众明白了什么 | 声音 |
|---|---|---|---|---|---|---|

- "画法"填第二节的六种之一，或者"停住""回场""合体"。
- "屏上是什么"用日常的词；"在干什么"用一个动词。
- "屏上的小字"是给这一句的证据：数字、名字、出处。一镜最多一条。
- 表前写清：一句话论点；全片的那个形象；那把尺子；哪两镜是同一个画面；每种颜色的意思。
- 表后写清：屏上所有的数是怎么来的；哪些是示意。

写完自己查：

- 遮住"字幕"一列，只读"屏上是什么，在干什么"，还看得出在讲什么吗？
- "画法"一列里，"只上字 / 停住 / 提问：不画"大约占五分之一吗？一个都没有，说明把结论也画了；占了一半，说明没找到形象。
- 有没有哪一镜的画面，换给另一段文案也成立？
- 每个场景是不是撑了两句以上，每句只改一处？
- 让人"哦——"的那一下在第几镜？它之前有铺垫、之后有停顿吗？

## 八、看图改图

第一次渲出来的画面几乎都有毛病，这是正常的。这种片子是看着图改出来的：`fold_C` 那 33 秒从第一张拼图到成片改了三轮。
下面这张表是改的过程中遇到过的毛病。看图的时候逐条对一遍。

| 看图时发现 | 多半是因为 | 改法 |
|---|---|---|
| 主体小小地缩在中间，像一条虚线、一撮点 | 尺寸是按"画得下"定的 | 先定屏幕上的大小：主体占画面宽度六成以上，主体里最小的单元（一颗珠子、一个字）不小于 20 像素；再反推缩放和排法 |
| 遮住字幕和小字，看不出这是什么 | 画成了记号 | 加体积和材质（明暗、高光、厚度）；或者从一个认得的画面推进去；还不行，回去换形象 |
| 字幕里说到的东西，屏上没有 | 分镜时漏了这个名词 | 把它画出来，或者改句子。开场尤其容易漏（字幕说"你的血里"，屏上没有血） |
| 一大片发白、发糊 | 实心的大色块吃了辉光 | 画进 `fr.look.under`；把 `fr.look.bloom` 调到 .5 左右 |
| 渐变里一圈一圈的硬边 | 用半透明叠层做软边，层数太少 | 叠十层以上、每层更淡；或者直接用径向渐变 |
| 东西是平的，像贴纸 | 没有明暗 | 靠边的暗一点，左上加一点高光，背后垫一层很淡的底 |
| 小字压在主体上，读不清 | 标注直接放在东西旁边 | 拉到主体外面，用一根细线连过去；一镜最多一条 |
| 有线或者东西伸进了字幕区 | 推近以后，别的部分被带了进来 | 退到暗处的东西连着线一起暗下去；纵向 80% 以下清空 |
| 字幕压在亮的底上看不清 | 镜头钻进了亮的东西里面 | 这一段把那个东西压暗 |
| 一句字幕里，画面变了三四处 | 贪多 | 拆成两句，或者删掉次要的 |
| 连着几句，画面没变 | 没给每句找到那"一处变化" | 回分镜表，每句写清改哪一处 |
| 转场中间有几帧说不清在干什么 | 两个状态之间直接插值 | 换成一个说得出名字的动作（钻进去、卷起来、卡上去、倒放回去）；或者压到半秒以内 |
| 推拉镜头先平移、后猛冲 | 缩放和焦点都在线性空间里插值 | 缩放在对数空间里走，焦点按 `1/缩放` 走（`fold_C` 的 `camAt`） |
| 和参考片并排一看，自己的又暗又空 | 主体不够亮、不够大，或者只有线没有面 | 主体放大；给它颜色和体积；背景可以暗，主体不能暗 |

改的时候守三条：

- **看图，不看代码。** "代码应该没问题"不算数。改完重截同样的时刻，确认毛病没了、别的没坏。
- **动的地方要看动的。** 静帧好看不等于转场说得清。用 `--motion` 在每个转场前后抽十来帧看。
- **拿别人的片子当尺子。** 把自己的静帧和参考片的帧、或者 `examples/` 里的 look 图并排放：主体有那么大吗？认得出吗？有那么干净吗？
