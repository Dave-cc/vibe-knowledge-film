# 文案：一份给人"读"的字幕稿

这类片子没有旁白，文案就是字幕。它不是口播稿删掉语气词，而是另一种文体：每句话都要配得上一个屏上动作，
而且短到观众一眼读完还有余力看画面。下面的规律都来自四条参考片的完整字幕（见 `analysis.md`）。

## 一、量

| | 每分钟句数 | 每句字数（均 / 最长） | 每句停留 | 全片 |
|---|---|---|---|---|
| B 寓言 | 15 | 13 / 18 | 约 3.5s | 185s ≈ 47 句 ≈ 616 字 |
| C 夜曲 | 8–10 | 15–21 / 31 | 5–6s | 300s ≈ 37 句 ≈ 793 字；334s ≈ 53 句 ≈ 771 字 |

- 一行放不下就是太长：A ≤ 21 字，B ≤ 18 字，C 中文 ≤ 28 字（C 下面还有一行英文）。超了就拆成两句、给两个动作。
- 全片有 26–42% 的时间**没有字幕**：片名、转场，以及让画面自己演的段落（模拟在跑、计数器在跳）。写稿时就把这些空出来。
- B 如果卡现成配乐：一句 ≈ 两个小节（112 BPM 时是 4.3 秒），一站 = 小节的整数倍。

## 二、骨架

```
钩子（6–24s）      先演一个小东西，末尾抛一个问题或一句对"你"说的话
片名（4–14s）      2–5 个字的片名 + 一句人话的副题
主体（70–80%）     4–12 站，每站一个画面装置
转向"你"           把全片的概念落到此刻的观众身上
回扣 + 末句        回到钩子的画面；最后一句是片名的回声
片尾（3–5s）       片名 + 文献线索
```

主体有三种排法，参考片里各用了一种：

**A 编年体**（一门学问的来历）。每站 = `年份 · 地点 · 人物` + 一个问题 + 一个做法 + 一个带数字的结果，2–3 句话，4–17 秒。
全片要有一条**悬着的线**把各站串起来：luck 在 1494 年抛出"赌注怎么分"，给了一个错答案（5 : 2），
"这道题，一悬就是 160 年"，隔了五站才回来解掉（15 : 1）。没有这条线，编年体就是流水账。
站与站的关系是递进：问题 → 第一次去数 → 发现要算顺序 → 算未来而不是过去 → 从赌桌走到城市 → 大数 → 曲线 → 公理。

**B 论证链**（一个机制为什么管住了我们）。顺序基本固定：
现象（一个动物实验，讲成故事）→ 规则（一句话，印成卡片）→ 再两例（说明不是个例）→ 权威锚点 + 给它命名 →
一个意外又好笑的例子 → **转到人**（两个你每天碰到的东西）→ 一张图把所有例子装进去 → 最狠的一例 → 落到你身上 →
三步解法（每步是一个动作）→ 回到开场的动物 → 规则卡。
"转到人"在 40–45% 处；解法只占 10%，不说教。

**C 侧面体**（一个抽象概念）。双钩子（一个容易的例子紧跟一个"坏掉"的例子）→ 片名 → 五章左右，
每章名只有一个字（猜 / 惊 / 余 / 噪 / 义；画 / 数 / 机 / 生 / 我），每章 = 一个能当场玩的小实验 + 一个"年份 · 人名"锚点 + 一句定义。
章的顺序是从手边的游戏走到人：先让观众玩，再给定义，再给反面，再给边界，最后落到"你"。
各章讲的最好是同一个结构的不同化身，这样图形能复用，结尾能把五章压成五个图标。

## 三、句式

下面每一种都在参考片里反复出现。写的时候不必凑齐，但末句、论点句、钩子句要从这里挑。

1. **两半句，后半句翻过来。** 前半句给直觉，后半句给事实，中间用分号或换行。
   - 摸一次，全凭运气；/ 摸上两万五千次，比例就会逼近真相。
   - 一个人的生死，谁也无法预料；/ 可一整座城的数字，却稳定得惊人。
   - 同样多的比特，可以是一首诗，也可以是一团乱码。
2. **破折号后面才是答案。** 术语和数字放在破折号之后，画面在破折号那一刻揭晓。
   - 这就是——大数定律。
   - 16 种未来，乙只赢 1 种——应分 15 : 1。
   - 把针随手撒在地板上，数一数压线的有几根—— / 竟然能算出 π。
3. **问句。** 每四到六句一个，问完下一句画面就去答。
   - 运气，能被计算吗？／真的公平吗？／最少要问几次？／烽火为什么值得点？因为敌人很少来。
4. **一句话写一个人。** 不写生平，只写一个让他像个人的细节。
   - 嗜赌的医生卡尔达诺，第一次认真地"数"运气。
   - 输急了的他，把问题交给了帕斯卡。
   - 他们清理了天线里的鸽子粪，噪声还在。／发明者后来说，他很内疚
5. **"不是……是……"只留给论点。** 全片一到三句，通常是末句或规则卡。
   - 它不笨，只是在照一条规则做
   - 冗余不是浪费，它是意义穿过噪声时的铠甲。
   - 假蛋赢，不是因为更好，而是因为更大。／怪圈不是故障，是世界回头看自己。
6. **直接对"你"说。** 钩子末尾一句，结尾一到两句。
   - 你的手机里，也有一颗／你一定猜到了下一个字。／此刻，是谁在读这句话？／这一次，由你来填。
7. **数字要具体到能上屏。** 160 年、25 : 27、51.8% 对 49.1%、两万五千次、39 分钟、二十瓦、543 位、10020 帧。
   写"很多次""差不多"的地方，回去查出那个数。
8. **引原话。** 每条片一到三处，外文原句 + 中文，标出处。引文出现时它就是画面主体，字幕可以停。
9. **末句是片名的回声。**
   - 《运气的形状》→ 但运气，从此有了形状。
   - 《信息论 · 惊奇之学》→ 惊奇，是世界正在告诉你新东西的声音。
   - 《自指 · 我是个怪圈》→ 怪圈不是故障，是世界回头看自己。

不出现的东西：寒暄和预告（"今天我们来聊""让我们一起"）、总结腔（"这告诉我们""综上"）、形容词堆叠、
"众所周知""值得一提的是"。句子是陈述句，主语是具体的人和东西。

## 四、一个比喻用到底

stim 全片只有一个比喻："假蛋"。它在第 2 句出现，之后奶茶是假蛋、短视频是假蛋、杜鹃是"最狠的假蛋"，
解法是"把假蛋挪出窝""把自己的蛋，放回窝里"，规则卡写"假蛋赢，不是因为更好，而是因为更大"。
观众不需要记住"超常刺激"这个术语也能复述整条片。

写稿时先定这个词：它得是钩子里**看得见的一个东西**，后面每一段都能用它造句。
luck 的"形状"、info 的"惊奇 / 猜不到"、loop 的"怪圈 / 停不下来"是同样的用法。

## 五、事实

- 每一站至少一个可核对的锚：年份、人名、地名、原著题名、数字。站与站之间的因果（谁写信给谁、谁解了谁的题）也要查。
- 屏上给出处：原著的原文题名 + 中文译名；论文写"作者 等, 年份"；示意图标"示意"；假说标"一种假说"；传闻写"据说"。
- 定理要带适用范围的小字（"适用于任何自洽、且足以做算术的公理系统"），这类小字不进字幕，放在画面上。
- 片尾一屏"文献线索 / 参考文献"，三到四行小字。
- 拿不准的事实，宁可换一个拿得准的例子。

## 六、标题和发布文案

- **片名** 2–5 个字，是概念本身或一个意象：运气的形状／超常刺激／信息论／自指。
- **副题** 一句人话，说清看完能得到什么：人类如何把偶然写进数学／为什么奶茶戒不掉，短视频停不下来／惊奇之学／我是个怪圈。
- **外文行** 拉丁文或英文大写小字，纯粹是气质：DE FORMA FORTUNAE／SUPERNORMAL STIMULI／INFORMATION THEORY · THE ART OF SURPRISE。
- **发布标题** 格式是"Vibe知识大赏 | 《片名》"，后面跟话题标签。
- **发布正文**（两条参考片这么写）：把片子前 30 秒的字幕连成一段话，从钩子讲到第一个结论为止，不剧透后半。

## 七、交稿格式

文案交给画面之前，写成一张表，一行一句。这张表就是分镜表的前两列（后面几列见 `visual-grammar.md`）。

```
# 起-止(s)  字幕（{词}=金，{!词}=红）               站 / 章
0.2-3.3     骰子落下之前，谁也不知道答案。           钩子
3.5-6.5     运气，能被{计算}吗?                      钩子（放大）
—           （片名，无字幕 6.6–10）
10.3-13.0   掷骰子，曾经是在向神发问。               序 · 古希腊
…
```

染色的规矩：金色给"答案 / 术语 / 关键数字"，红色给"错的 / 危险的 / 过头的"。一句里最多染一处，三句里至少两句不染。
