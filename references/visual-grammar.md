# 画面语法：常见句型的演法、版式和动效

先读 `visualization.md`——怎么给概念找形象、每句用哪种画法、什么时候不画，在那里。这一份是定了画法之后的速查：常见句型、版式、常驻元素、颜色、转场、手感。

原则只有一条：**字幕说什么，屏上就发生什么，而且是真的发生。**
"摸上两万五千次，比例就会逼近真相"——屏上真有一个计数器数到 25,000，一条折线真的贴向 3/5。
观众读一句、看一个动作，两者互相印证，所以不需要旁白。

## 一、先问这句话是哪一类

| 这句话在说 | 画面这样演 | 参考片里的例子 |
|---|---|---|
| 一个数量、一个比分 | 让它"长出来"并且数得清：分段进度条逐格亮、数字从 0 数上去、一个东西被切成几份 | 甲 50 · 乙 20 的六格进度条；金币切成 5 : 2 |
| A 比 B | 左右两栏，版式完全一样，只有内容和颜色不同；最后各盖一个结论 | 赌局 A / B 两张卡（51.8% 金、49.1% 红、"赢""输"小印）；9 点 vs 10 点；逼真模型 vs 红棍子的两个计数器；乱码 vs 诗 |
| 个别没规律，合起来有规律 | 粒子模拟：成百上千个独立的随机小东西落下来，堆出一个形状 | 高尔顿板；布丰投针；死亡公报化成一城的点；硬币直方图 |
| 越来越接近 | 一条实时折线 + 一条目标虚线 + 一个在跳的计数 | 陶瓮摸石子，折线贴向 3/5 |
| 有多少种可能 | 把所有可能画成一棵树，按结果上色，在叶子上数 | 16 条未来：15 条金线归甲，1 条红线归乙 |
| 一个方法、一个过程 | 当场跑一遍：每一步屏上一问一答，角上挂着状态 | 二分法："比 512 大吗？是"，左上"第 N 问"，右上"剩余 N 种可能" |
| 一个公式、一个定义 | 先有例子，公式最后出；每个符号都对得上刚才屏上的东西；旁边一行人话 | 先下雪、上头条，再出"惊奇 = −log₂ p"；"熵"旁边写"平均的惊奇" |
| 谁包含谁、谁比谁大 | 集合图：一个圆在另一个圆里 | "可证"的小圆在"真"的大圆里，G 落在两者之间 |
| 悖论、停不下来 | 一个光点在两个字之间来回弹，越弹越快；或者一个环 | 真 ⇄ 假；停 ⇄ 转；莫比乌斯环 |
| 一句名言 | 引文自己当主体：外文原句小字斜体 + 中文大字 + 出处，背后一幅和说话人有关的淡图 | 拉普拉斯的话压在行星轨道上 |
| 某年某人 | 不画脸。角上的年份、地点·人物 + 一件那个时代的东西；人只以剪影出现 | 羊距骨、信封、死亡公报、打字机新闻稿；诺奖三位得主的椭圆剪影 |
| 从这里到那里、谁写信给谁 | 一幅轮廓线地图，两个点，一个东西沿虚线飞过去 | 巴黎 ⇄ 图卢兹之间往返的信封 |
| 给一个概念起名 | 大字 + 辉光，前面出现过的道具围过来 | 红色大字"超常刺激"，蛋、红棍子、红肚皮木头围着它 |
| 一条规则、一句结论 | 印成一张卡片，郑重其事 | 横线纸卡"孵蛋的规则"；金章规则卡 |
| 为什么会这样（机制） | 一张坐标图，把全片出现过的例子都放进去；坐标轴用人话 | "本能有多想要 × 刺激有多强"；"甜 × 油"散点图 |
| 这就像那个（比喻） | 让比喻的两端在一个画面里合体 | 鸟窝里卧着一台亮着的手机 |
| 该怎么做 | 顶上一排步骤标签逐个点亮，每步一个动作 | 1/3 挪出窝 · 2/3 缩回正常 · 3/3 放回来 |
| 关于语言、文字的例子 | 让字自己演：逐字打出、留空位、候选字滚动、每个字底下一根柱、字序打乱、方块盖住、划掉重写 | info 全片 |
| 噪声、干扰 | 一条抖动的波形，同时整个画面真的蒙上噪点 | info 的 04 章 |
| 很远、很大、很久 | 一条线，两个端点，一格格往回传的光点，旁边标数 | 旅行者 1 号 → 地球，"光也要走将近一整天" |
| 回顾 | 前面每章缩成一个小图标排成一排，逐个点亮，一个配一句 | loop 尾声的五个图标 |

找不到对应的类？先回去看文案：一句既不能数、不能比、不能演的话，多半是一句应该删掉的议论。

## 二、一屏只讲一件事

- **一个主体。** 每一刻屏上只有一样东西是亮的、在动的；别的东西要么退到三成以下的亮度，要么离场。
- **三个区，不串位。** 以 1920×1080 计：
  - 主体区：纵向 12%–78%。主体常居中，或"图在左、结论在右"。
  - 字幕区：纵向 80%–95%，只放字幕（C 的英文行也在这里）。任何图形伸进来都要让开。
  - 四角：常驻元素（年份、章节标、仪表、出处）。
- **标注贴着东西。** 说明文字紧挨它说的那个东西，用小字、灰色；需要指的时候用一根细引线。
- **留黑。** 画面三成以上是空的底。别用装饰填空。

## 三、常驻元素：每个都带数据

全片从头挂到尾的东西只有两三样，而且每样都在"报数"：

| 世界 | 常驻 | 它报什么 |
|---|---|---|
| B | 左上仪表「本能读数」：0–150 的表盘，100 以上是红区"超常"，下面一行"对象：×××" | 眼前这个东西有多"超常"——同一把尺子量遍全片 |
| C | 左上极小的章节标：`03  余  REDUNDANCY` + 一条细线 | 现在是第几章 |

B 的仪表是个好范例：把全片的核心概念做成一个仪器，每来一个新例子就拿它量一次（自己的蛋 60 → 假蛋 149 → 奶茶 122 → 无限下滑 153）。
你的片子的核心概念能不能做成一个读数？能的话，观众会自己拿它去比。

参考片角上还有作者水印，片名卡上有"×× 出品"；本 skill 不加任何水印和署名。

## 四、颜色是词汇

每种颜色全片只有一个意思，从第一次出现到最后不变：

| | 金 | 红 | 冰蓝 | 灰 |
|---|---|---|---|---|
| B | 规则句 | "超常"的一切：红晕、仪表红区、关键词 | — | 标注 |
| C | 惊奇、真、被点亮的 | 错、噪声、矛盾 | 已知、平常、可证、停下 | 标签 |

所以 info 里刻度上的点是冰蓝还是金色，本身就在说话；loop 里字变玫红就是"错了"。定稿前写下这张表，然后不许破例。

## 五、镜头怎么接

镜头之间几乎没有硬切。新画面是从旧画面里**长出来**的：

| 接法 | 做法 | 时间 | 例子 |
|---|---|---|---|
| 溶解 | 旧的淡出、新的淡入，重叠一半 | 0.5–0.7s | 默认 |
| 变形 | 同一个几何体换一种画法 | 0.55s | 实体骰子 → 金线框立方体，六面换成 1/6 |
| 留一个点 | 上一幕的某个点不消失，滑到新位置变成下一幕的东西 | 0.9s | 刻度上的金点滑到正中 → 闪亮 → 变成沿线飞的光点 |
| 闪 | 整幅提亮再落回，新画面在亮的时候换进来。《运气的形状》：0.3s 升到顶、0.4s 落回，暖米色；C：一帧到顶、约 0.35s 落回 | 0.4–0.7s | 进片名；C 每章开头；定理落地 |
| 推近穿过 | 当前画面以某一点为中心放大到两倍，同时淡出 | 1.3s | 命运之轮迎面推来，穿过去是 1494 年 |
| 压暗 | 场景暗到底，片名的光从上面浮出来 | 0.55s | B 的冷开场 → 片名 |
| 收进胶片 | 前几个镜头缩成胶片带上的几格，整条带子斜着滚走 | 1.2s | B：三个实验 → 诺奖 |
| 卡片盖上来 | 一张纸卡从下面升上来盖住场景，带一点倾角 | 0.5s | B 的规则卡、新闻稿 |
| 暗一下 | 整幅暗到接近全黑再亮，角上的章节标同时换 | 约 1s | C 的章与章之间 |
| 回到同一画面 | 结尾重画开场，机位、颜色都一样，只改一处 | — | 四条片的结尾 |

片名卡之外，章节内部还有一种"同屏换内容"：版式不动，只把里面的东西换掉（stim 的银鸥 → 刺鱼）。这也是省工的地方。

## 六、动效的手感

- **字是显影出来的，不是飞进来的。** 《运气的形状》：每个字从虚（约 9px 模糊）到实，一个字 0.34 秒，字与字错开 0.085 秒，整句不超过 1 秒出完。
  B：逐字亮起，不虚。C：整行 0.55 秒淡入，英文晚 0.18 秒。没有弹跳、没有从屏幕外滑入。
- **线是画出来的。** 曲线、轮廓、连线都从一端长到另一端，线头带一个小光点。
- **数是数上去的。** 结论数字用 0.9 秒从 0 滚到位（先快后慢）；模拟里的计数每帧都在变。
- **东西有重量。** 落下来的东西先加速、落地弹两下、越弹越低，脚下有影子。盖章是 0.18 秒砸下来加一下震动。
- **永远有一点点在动。** 尘埃在漂、星点在闪、骰子在极慢地转、辉光在呼吸。但主体出完之后就停住让人读——
  参考片有三分之一的帧几乎不变。
- **镜头只做慢推和慢移。** B 的场景分层：角色层从 1.7 倍拉到 1 倍，远景层只动它的两成，前景的草动得更多。
- **强调靠亮度，不靠尺寸。** 重点是变亮、发光、换成金色；只有极少数句子（全片一两句）把字幕本身放大。

## 七、分镜表

文案定稿后，给每一句补上后四列。写不出"屏上动作"的句子，回去改文案。

| 起–止 | 字幕 | 这句是哪一类 | 屏上动作（谁、怎么动、停在哪） | 屏上的字（标注、数字、出处） | 声音 |
|---|---|---|---|---|---|
| 17.0–19.3 | （无） | 某年某人 + 数量 | 年份滚到 1494；甲 50、乙 20 数上去，两条六格进度条逐格亮；中间落下一枚金币 | 先到 60 分者，赢走全部赌注 / 甲 / 乙 / 60 分 · 胜 / 赌注 | 配乐满编进入 |
| 19.3–22.0 | 比赛被迫中断——桌上的钱，该怎么分？ | 问句 | 朱印"中断"砸在金币上方，金币震一下 | 中断 | 盖章声 |
| 22.2–24.6 | 帕乔利的答案：按已得分数，5 : 2。 | 数量 | 朱印淡出；金币裂成一大一小两块，分开 | 5 : 2 | — |
| 24.9–27.0 | 真的公平吗？这道题，一悬就是 {160 年}。 | 问句 | 5 : 2 后面跳出一个红色问号 | ? | — |

检查这张表：

- 每一行都有屏上动作，而且动作在字幕出现后的 0.3 秒内开始。
- 相邻两行的主体不同，或者同一个主体做了不同的事。
- 每 20–30 秒有一处"画面自己演"的无字幕段落。
- 钩子的画面在最后一分钟里再出现一次。
- 全片的母题（那个图形或那个比喻）至少出现在三站里。
