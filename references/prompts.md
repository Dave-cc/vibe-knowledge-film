# 逆向出的提示词

先说清楚：**这不是原作者的原话。** 原作者给模型说了什么，从成片里拿不到。
这里做的是倒推——成片里每一个看得见的决定（片名为什么不在第一秒、年份为什么会滚、数字为什么在跳、角上为什么有出处），
都应该能在 brief 里找到一句对应的话。把这些话收齐，就是下面的东西。

分三层用：

1. **完整 brief**：一次把要求说全。适合直接交给模型开工。
2. **分步提示词**：一轮只定一件事，每轮看过再往下。四条参考片更像是这样做出来的（`analysis.md` 第四节列了迭代痕迹）。
3. **返工话术**：成片不对劲时，一句话指出毛病并说清要什么。

用本 skill 的时候不需要把这些贴给模型——`SKILL.md` 的流程已经包含了它们。这份文档给两种人：想在别的模型或别的工具里复现的人，和想知道"好片子的要求到底是哪些"的人。

## 零、为什么一句话不够

这波视频里流传最广的说法是"一句提示词直出"。常见的那一句是：

> 制作一段 15 秒的动态图形视频，充分展现你作为动态设计师的出色实力，尽情发挥创意。

它确实能出片，但出的是炫技片：同样的配色、同样的方块网格、同样的收尾 logo。知识片不一样——
130 秒里有 14 个年份、十几个人名、三十句字幕、十几个各不相同又都在真算的装置，还要前后呼应。
这些内容得有人（或者前几轮对话）先定下来。所以下面的 brief 都很长，长的部分几乎全是**内容和规矩**，不是形容词。

## 一、完整 brief 模板

方括号里是要填的。填不出来的项，说明那一步还没想清楚，先回去想。

```text
做一条 [时长] 的知识短片《[片名]》，16:9，1920×1080，30fps。全片用代码逐帧画出来，不用任何图片和视频素材。

【讲什么】
- 一句话论点：[看完之后观众能复述的那句话]
- 贯穿全片的一个意象 / 比喻：[钩子里看得见的一个东西，后面每段都用它]
- 观众：刷到这条视频的普通人，横屏看手机。不需要任何前置知识。

【没有旁白】
全片没有人声，靠底部字幕讲。所以：
- 字幕每句不超过 [18–25] 个字，一句只说一件事；全片 [N] 句左右，每分钟 [8–15] 句。
- 每句字幕出现时，画面上必须有一个对应的动作在发生；字幕说到数字，屏上要有那个数字。
- 留出几段没有字幕、只让画面自己演的时间（片名、转场、模拟在跑的时候）。

【结构】
1. 钩子（[6–24] 秒）：不出片名。先演 [一个具体的小东西]，最后一句 [抛一个问题 / 对"你"说一句话]。
2. 片名卡（[4–14] 秒）：[片名] / 副题"[一句人话]" / 外文一行 [拉丁文或英文]。片名下面放本片的母题图形：[……]。
3. 主体 [N] 站，按这个清单来（每站：谁、哪年、什么问题、屏上用什么装置演、结论数字）：
   - [站 1 ……]
   - [站 2 ……]
   …
4. 转向"你"：[把概念落到今天的观众身上的那一句]
5. 结尾回到钩子的画面，只改一处：[……]。最后一句字幕是片名的回声：[……]
6. 片尾：片名 + 三行文献线索。

【画面世界】[B 寓言 / C 夜曲，或自己描述：]
- 底：[……]
- 颜色只用这几种，每种全片只有一个意思：[金 = …，红 = …，冰蓝 = …]
- 字体：中文 [粗宋 / 细宋 / 粗黑]，西文 [衬线斜体 / 等宽小标]。
- 全片常驻的东西只有这几样，每样都在报一个数据：[左上年份 + 地点·人物 / 右上出处 / 仪表 / 章节标]
- 一屏只讲一件事。主体在画面中上部；底部 80%–95% 只放字幕，别的东西不许伸进去。

【每个装置都要真的算】
[大数定律的折线用真的随机抽样画；投针真的数压线；二分法真的问十次。] 屏上的计数、比例、结论数字来自这次计算，不是写死的。
但要用固定的随机种子：同一帧不管渲染多少次都一样。

【动效】
- 字幕 [逐字由虚变实 / 逐字亮起 / 整行淡入]，不许弹、不许从屏幕外飞进来。关键词染 [金]，负面词染 [红]，一句最多染一处。
- 线是画出来的（线头带一个光点），数字是数上去的，东西落下来要有重量。
- 镜头之间不硬切：溶解、变形、推近，或者留一个点滑到下一幕。进片名用一次闪白。
- 主体出完就停住让人读。任何时候背景里都有一点点东西在动（尘埃 / 星点）。

【事实】
先给我一张事实表：每一站的年份、人名、地点、原著的原文题名和中文译名、要用到的每个数字，标上你有多确定。
拿不准的换一个拿得准的例子。屏上给出处；示意图标"示意"，假说标"一种假说"。

【声音】[卡这首配乐：…… BPM，一句字幕两小节 / 全部用代码合成：低频长音垫底，每章开头一记和弦，屏上每打一个字一声]

【技术】
一个 HTML 页面 + 一张 Canvas。暴露 seek(t)：给定时间 t 画出那一帧，画面只取决于 t，不保留任何跨帧状态。
用 Playwright 逐帧 seek、截图、管道进 ffmpeg。先别渲染全片。

【流程】
1. 先给事实表和字幕稿（带时间），我确认。
2. 再给分镜表：每句字幕对应的屏上动作、屏上的字、声音。
3. 截三张样帧给我看：钩子、片名、一个典型的站。
4. 先做前 30 秒，渲出来。
5. 再铺全片，一章一个函数。每做完一章，截一张拼图自查。
6. 最后合声音。

【自查】交片前逐条过：
- 把片子静音、遮住字幕看，能不能看出每一段在讲什么？
- 只读字幕不看画面，是不是一篇通顺的短文？
- 钩子的画面在结尾回来了吗？母题出现了至少三次吗？
- 每个数字都核对过吗？每一站都有出处吗？
- 有没有哪一秒，屏上同时有两样东西在抢着动？
```

## 二、三条参考片的逆向 brief

把模板按成片填回去，就是下面三份。其中 A 是参考片笔记，现在可选的外观只有 B 和 C。

### A 鎏金暗场 ——《运气的形状》

```text
做一条 130 秒的知识短片《运气的形状》，16:9，1920×1080，30fps，全片用代码逐帧画，不用任何素材。

讲什么：概率论是怎么从赌桌上一步步变成数学的。论点：运气不可预测，但它有形状。
贯穿全片的意象：一颗骰子，和一条钟形曲线。

没有旁白，靠底部字幕讲。全片 30 句左右，每句不超过 25 个字。

结构：
1. 钩子 6 秒：一颗象牙色的骰子翻滚着落在暗色桌面上，停住。字幕"骰子落下之前，谁也不知道答案。"
   骰子溶成金色线框立方体，六个面各写 1/6，外面一圈星盘刻度。字幕放大："运气，能被计算吗？"（"计算"染金）
2. 闪白，片名卡 4 秒：拉丁文 DE FORMA FORTUNAE / 金色大字"运气的形状" / 一条钟形曲线由一个光点从左画到右 / "人类如何把偶然写进数学"。
3. 主体按年代走，每站左上角一个年份、下面"地点 · 人物"，右上角给原著（原文题名斜体 +《中文名》+ 一枚朱红小印"文献"）：
   - 序（无年份）：古希腊·古罗马，四块羊距骨落下，后面命运之轮转起来。"掷骰子，曾经是在向神发问。"
   - 1494 威尼斯 帕乔利《算术大全》：先到 60 分赢，甲 50 乙 20 时比赛中断，赌注怎么分？他按已得分数分 5 : 2。"真的公平吗？这道题，一悬就是 160 年。"
   - 约 1564 卡尔达诺《论赌博游戏》：把骰子展开成六个面，概率 = 有利的情形 ÷ 所有等可能的情形。
   - 约 1620 伽利略：三颗骰子凑 9 点和 10 点都是 6 种组合，为什么 10 点更常出？因为顺序也要算：25 种对 27 种。
   - 1654 德·梅雷：一颗骰子掷 4 次至少一个 6（51.8%）对两颗骰子掷 24 次至少一个双 6（49.1%）。
   - 1654 帕斯卡 × 费马通信：回到 1494 年那道题，别数过去的比分，数还没发生的未来——16 种未来乙只赢 1 种，应分 15 : 1。
   - 1662 格朗特《关于死亡公报的自然与政治观察》：一个人的生死无法预料，一座城的数字却很稳定。
   - 1713 雅各布·伯努利《猜度术》：坛子里白石 3000 黑石 2000，摸得越多比例越接近 3/5。大数定律。
   - 1733 棣莫弗：同时抛的硬币越多，直方图的柱子越细，一条钟形曲线浮现。
   - 1777 布丰：往地板上撒针，数压线的根数，能算出 π。
   - 1814 拉普拉斯《关于概率的哲学随笔》：引原话"概率论，说到底，不过是把常识化成了计算。"
   - 1873 高尔顿：钉板上落下成千上万颗珠子，堆出同一个形状。引他的话。
   - 1933 柯尔莫哥洛夫《概率论基础》：三条公理。
4. 2026 · 此刻 · 你：开场那颗骰子回来，身后多了一条很淡的钟形曲线。
   "下一次会掷出几点？依然没有人知道。" / "但运气，从此有了形状。"
5. 片名卡 + 三行文献线索。

画面世界：近黑的暗场，漂着失焦的尘埃，四角压暗。古代和文艺复兴用暖棕黑，17 世纪以后转冷蓝黑，结尾回暖。
颜色只有象牙白、金、朱红：金 = 答案和关键数字，红 = 错的那一边。中文用粗宋，数字和西文用细衬线体。
年份换站时像里程表一样逐位滚到新年份。

每个装置都要真的算：摸石子的折线、投针的 π、硬币直方图、钉板，全部用固定种子的随机数现场模拟，屏上的计数跟着跳。

动效：字幕逐字由虚变实，约一秒出完一句。线是画出来的，线头带光点。东西落地要弹两下。站与站之间溶解，不硬切。

声音：卡一首约 112 BPM 的配乐，一句字幕两小节；配乐满编进入的那一拍对 1494，抽空后再进的那一下对"π ≈ 3.14"。

（技术、流程、自查同模板。）
```

### B 寓言 ——《超常刺激》

```text
做一条 185 秒的知识短片《超常刺激》，副题"为什么奶茶戒不掉，短视频停不下来"。16:9，全片用代码画。

讲什么：动物的本能有一条"越多越好"的规则，自然界里这条规则有上限所以不出事；人造的东西冲破了上限。
论点印成一句话：假蛋赢，不是因为更好，而是因为更大。
全片只用一个比喻："假蛋"。奶茶是假蛋，短视频是假蛋，解法也用"窝"和"蛋"来说。

没有旁白，底部字幕，47 句左右，每句不超过 18 个字，口气像讲故事。

结构：
1. 冷开场 8 秒：海滩上，一只蛎鹬离开自己窝里的三颗小蛋，扑上一颗比它还大的黄斑假蛋。机位由近拉远。
   "一只鸟，丢下了自己的蛋 / 去孵一颗大得离谱的假蛋 / 你的手机里，也有一颗"
2. 场景压暗，金字片名卡。
3. 实验（泛黄旧片色调，"20 世纪中叶 海边沙丘"）：廷伯根在窝边放假蛋，一颗比一颗大，鸟一次次挪过去；最后一颗和它一样大，它爬上去、滑下来、再爬。
   左上角挂一个仪表「本能读数」（0–150，100 以上是红区"超常"），下面一行"对象：×××"。全片每出现一个新东西，就用它量一次。
4. 规则卡：一张横线纸卡，四颗由小到大的蛋，对勾越来越大。"它不笨，只是在照一条规则做 / 蛋越大，越值得孵"
5. 再两例，用同一个版式（顶上一行"年份 · 结论"，左右两个计数器比真的和夸张的）：银鸥雏鸟更爱啄红棍子；雄刺鱼更想揍红肚皮木头。
6. 1973 诺贝尔生理学或医学奖：奖章、三位得主的剪影（不画脸）、新闻稿原文一句 + 中文。给它命名：红色大字"超常刺激"。
7. 一个好笑的例子：1983 年澳洲，雄甲虫爱上啤酒瓶（棕色、亮、带凸点、超大号）。"人类随手一扔，就造出了一颗假蛋"
8. 转到人（夜里的书桌：奶茶、橙子、手机）："而今天，我们给自己造了很多颗"
   - 甜 × 油的散点图：自然界里又甜又油的几乎只有母乳，奶茶正好落在那个空位上。
   - 屏幕：以前的网页有底；2006 年无限下滑被发明出来。
9. 一张图讲透：横轴"刺激有多强"，纵轴"本能有多想要"，一条直线；自然界的东西到一条竖线"自然界的上限"为止，
   右边是红色的"超常区"，线继续往上。"所以本能从来不需要刹车"
10. 最狠的一例（黄昏的芦苇荡）：杜鹃雏鸟住进了别人的窝，一张大红嘴让养父母停不下来，而它们自己的蛋早被推出了窝。
11. 落到你：鸟窝里卧着一台手机。"你的睡眠、朋友、没看完的书 / 也是这样，被一颗颗挤出了窝"
12. 三步解法，顶上三个标签逐个点亮：挪出窝（手机放卧室外）/ 缩回正常（屏幕调成灰度）/ 放回来（把自己的蛋放回窝里）。每步是一个动作。
13. 回到开场的海滩：假蛋被拿走，鸟回到自己的蛋上。
14. 规则卡 + 片名 + 四条参考文献。

画面世界：每个地点一幅扁平插画（大色块、柔和渐变、不描边），分远景 / 角色 / 前景三层，镜头推拉时有视差。
角色用几个色块拼成，动作只做走、低头、扑翅、卧下。人物只画手或剪影。
"超常"的东西永远带红：红晕、红区、红色关键词。字幕用粗黑体，暖白色，规则句整句金色。

每个出处都上屏：年份、研究者、"示意"、"2020 年研究：调成灰度，平均每天少用 39 分钟"。

声音：卡同一首配乐。片子比配乐长的话，把配乐重新开始的那个点对在第 12 段的转折上。

（技术、流程、自查同模板。）
```

### C 夜曲 ——《信息论 · 惊奇之学》（《自指》同法）

```text
做一条 5 分钟的知识短片《信息论》，副题"惊奇之学"，英文 INFORMATION THEORY · THE ART OF SURPRISE。16:9，全片用代码画。

讲什么：信息的多少，取决于它有多让你意外。论点：惊奇，是世界正在告诉你新东西的声音。
贯穿全片的意象：一道填空题，和一个光点。

没有旁白。底部中文字幕，下面跟一行英文（意大利体，小一号）。37 句左右，每句最多两个分句。

结构：
1. 双钩子，不出片名：
   - 屏幕中央逐字打出"床前明月＿"，空位闪着金色光标。那个"光"字自己浮出来。下面一条刻度「惊奇 SURPRISE」，蓝点停在最左边：≈ 0 bit。
     "你一定猜到了下一个字。/ 所以它出现的时候，几乎没有带来任何新东西。"
   - 再打出"那天夜里，窗外下起了＿"，空位上候选字不停地滚（雪、鱼、星、花、灰、火……），停不下来。刻度被一条金线推到很右：? bits。
     "这一次，你猜不到。而猜不到的，才是信息。"
2. 刻度上那个金点滑到屏幕正中，一帧闪亮，光点拖着彗尾沿一条横线飞过，几千个点聚成片名。片名停十几秒，不出字幕。
3. 分章，每章左上角一个极小的章节标（编号 + 一个字 + 英文）：
   - 01 猜：我想了一个 1 到 1024 之间的数，你只能问是或否。屏上真的用二分法问十次（"比 512 大吗？是"），区间条每次砍半，
     左上"第 N 问"、右上"剩余 N 种可能"，下面攒出十位 0/1。结论 log₂ 1024 = 10 bits。1948，香农，贝尔实验室。
   - 02 惊：烽火为什么值得点？因为敌人很少来。p = 364/365 → 0.004 bit；p = 1/365 → 8.5 bits。
     "广州明天下雪"将近 10 比特——屏上真的下雪，弹出一条头条。然后才出公式：惊奇 = −log₂ p；平均的惊奇叫熵。
   - 03 余：地铁广播"下一站是终点站，请带好您的随身物品。"每个字下面一根柱子表示它有多难猜。
     把一句话的字序打乱（字幕也跟着乱），你还是读得懂——猜得到的部分叫冗余。用方块盖掉一半的字，仍然读得懂。
     "冗余不是浪费，它是意义穿过噪声时的铠甲。"
   - 04 噪：噪声越来越大（画面蒙上噪点，声音里也铺进噪声）→ 一帧闪亮 → 彻底静音两秒 → 信道容量公式。
     旅行者 1 号，二十瓦，光要走将近一整天，地球仍然能认出每个比特。1964 年贝尔实验室那段消除不掉的噪声，是宇宙微波背景。
   - 05 义：香农原话——意义不在他的公式里。同样 112 比特，左边是乱码，右边是"春风又绿江南岸"。
     推荐流只给你意料之中的东西。"今天你看到的东西里，有多少是你没有料到的？"
4. 尾声：山头上的烽火台一座座亮起来——一本读不懂的书，一个和你想得不一样的人，一条没走过的路。
   "惊奇，是世界正在告诉你新东西的声音。"
5. 回到"那天夜里，窗外下起了＿"，空位亮着。"这一次，由你来填。" 片名。

动效：大字是逐字"打"出来的；字幕整行淡入。章与章之间整幅暗一下。每章开头可以有一帧闪亮。

声音：全部用代码合成，不用现成配乐。低频长音垫底；每章开头一记带泛音的和弦；屏上每打一个字、每问一次都有一声轻响；提问时一个上滑音。整体要安静。
```

## 三、分步提示词

一轮只定一件事。每轮后面写了"过了再往下"的标准。

**第 1 轮 · 立题和事实表**

```text
我想做一条 3 分钟左右、没有旁白、靠字幕和画面讲的知识短片，题目是 [……]。
先别写文案。给我：
1. 一句话论点（观众看完能复述的那句）。
2. 一个贯穿全片的意象或比喻：它必须是开头能直接画出来的一个东西。
3. 6–12 个"站"的清单：每站一个年份或一个场景、一个人、一个问题、一个能在屏上演出来的小实验、一个结论数字。
4. 事实表：上面用到的每个年份、人名、题名、数字，各自的出处和你的把握程度。把握不足的标出来。
```
过关：论点能一口气说完；意象画得出来；每站的"小实验"你自己能想象出画面。

**第 2 轮 · 字幕稿**

```text
按这个清单写字幕稿。它不是口播稿：没有人念，观众是读的。
- 每句不超过 20 个字，一句一件事。全片 [N] 句左右。
- 开头不要自我介绍和预告，直接是钩子。钩子最后一句要么是个问题，要么对"你"说。
- 每站 2–3 句：问题、做法、结果。结果里要有具体数字。
- 术语和数字放在破折号后面。
- "不是……是……"全片最多用两次，留给论点。
- 结尾回到钩子的画面，最后一句是片名的回声。
- 不要"让我们""众所周知""值得一提""这告诉我们"。
写成表：序号 / 字幕 / 属于哪一站 / 这句话屏上要发生什么。
```
过关：遮住最后一列，只读字幕是一篇通顺的短文；每一行的最后一列都填得出来。

**第 3 轮 · 定世界，看样帧**

```text
先别做动画。用一个 HTML + Canvas 页面，给我三张 1920×1080 的静帧：钩子、片名卡、一个典型的站。
世界是 [B 寓言或 C 夜曲，或者自己的描述]。颜色只用 [……]，每种一个意思。
字幕在底部 85% 高度，[字体字号]。角上常驻 [……]。
三张图要看得出是同一条片子。
```
过关：三张图缩成手机横屏大小，字幕还读得清；颜色的含义和你定的一致；画面有三成以上是空的。

**第 4 轮 · 分镜表**

```text
把字幕稿扩成分镜表。每一句字幕一行，补上：
起止时间 / 这句话是哪一类（数量、对比、过程、定义、引文……）/ 屏上动作（谁、怎么动、停在哪）/ 屏上的字（标注、数字、出处）/ 声音。
相邻两行不能是同一个主体做同一件事。每 20–30 秒留一段没有字幕、画面自己演的时间。
哪些装置要真的模拟，列出来，写明用什么算法、最后停在什么数。
```
过关：每个模拟的"最终数字"和事实表对得上。

**第 5 轮 · 前 30 秒**

```text
现在做前 30 秒（钩子 + 片名 + 第一站），渲成视频。
画面必须是时间 t 的纯函数：暴露 seek(t)，不保留跨帧状态，随机数用固定种子。逐帧截图进 ffmpeg。
先截 8 张拼成一张图给我看，没问题再渲。
```
过关：不看字幕能看懂在演什么；字幕出现后 0.3 秒内屏上有动作；片名是被"引出来"的，不是切过去的。

**第 6 轮 · 铺全片**

```text
按分镜表铺完全片。一站一个函数，常驻元素（年份 / 仪表 / 章节标、字幕）在最外层统一画。
同类的站用同一个版式换内容。每做完两三站，均匀截 16 张拼图自查一次：有没有字压在字幕区、有没有两样东西同时在抢。
```

**第 7 轮 · 声音**

```text
[A / B] 我给你一首配乐。量出它的速度和每个乐句的起点，把每一站的开头对到小节线上，最大的那次揭晓对到配乐重新进入的那一拍。
[C] 用代码合成全部声音：把屏上的事件列成表（时刻、类型），每类事件一种声音；章节开头一记和弦；定理那一下之后静音两秒。
```

**第 8 轮 · 终检**

```text
全片渲出来之后，按这个清单逐条自查，把不合格的时间点列给我：
静音看一遍 / 只读字幕一遍 / 每个数字核对 / 每站有出处 / 钩子回扣 / 母题至少三次 / 没有硬切 / 没有东西伸进字幕区 /
没有哪一秒两样东西同时在动 / 最后一帧是片名和文献。
```

## 四、返工话术

成片不对劲时，说清"哪里、怎么不对、要什么"。下面每一条都对应参考片里一个看得见的做法。

| 看到的毛病 | 这样说 |
|---|---|
| 第一秒就是片名 | 片名往后放。先用十秒演 [那个东西]，问出问题，再闪一下亮出片名。 |
| 字幕整行弹出来，或者从下面滑上来 | 字幕原地显影：逐字由虚变实，一秒内出完，不要位移，不要弹。 |
| 图是一张静态图表 | 让它真的算。从第 1 次画到第 N 次，计数器跟着跳，最后停在 [这个数]。 |
| 一屏里东西太多 | 一屏只讲一件事。这句话只留 [主体]，别的降到三成亮度或者先离场。 |
| 颜色越用越多 | 只许用 [金、红、冰蓝]。金 = 答案，红 = 错的 / 过头的，蓝 = 平常的。把不符合的改掉。 |
| 镜头是硬切的 | 不要切。让上一幕的 [那个点 / 那个形状] 留下来，变成下一幕的 [……]。 |
| 转场花哨（旋转、翻页、故障效果） | 只用溶解、推近、变形、闪。全片最多三次闪。 |
| 结尾是一段总结 | 不要总结。回到开场的画面，只改 [一处]，最后一句是 [片名的回声]。 |
| 看不出现在讲到哪了 | 左上角挂一个 [年份 / 章节标 / 读数]，全片都在，换站的时候它跟着变。 |
| 屏上没有任何出处 | 每一站在角上给出处：原文题名 +《中文名》+ 作者·年份。示意图标"示意"。 |
| 节奏一个速度到底 | [某句] 是全片最重的一句：前面留两秒只有画面，这句字幕放大，出完停三秒。 |
| 所有东西都在发光，糊成一片 | 辉光只给光点、细线和大字。实物（骰子、卡片、角色）不发光。 |
| 字太小 | 按手机横屏看：字幕不小于 48px，标注不小于 20px，再小的删掉。 |
| 字幕读起来像口播稿 | 这是给人读的。删掉"我们""其实""那么"，每句砍到 20 字以内，一句话拆成两句、给两个动作。 |
| 历史人物画成了卡通脸 | 不画脸。用年份、地点、一件那个时代的东西代表他；非要出现人，用剪影。 |
| 元素进场都是弹一下 | 去掉所有弹跳和回弹。字是显影，线是画出来，数是数上去，只有真的东西落地才弹。 |
| 每一章各画各的，像几条片拼的 | 全片只用 [一个光点 / 一颗蛋 / 一条曲线] 这一套图形。第 [N] 章改成用它来演。 |
| 标注和图形压到字幕上了 | 底部 80%–95% 只放字幕。把 [那个东西] 往上挪。 |
| 配乐和画面各走各的 | 把 [这一站] 的开头对到配乐的 [这一拍]。字幕一句两小节。 |
| 片子改长了，配乐不够 | 让配乐在 [这个转折] 的地方重新开始，别在句子中间断。 |
| 模拟每次渲染结果不一样 | 所有随机数用固定种子，按帧号或序号取，不要用会变的随机源。 |
| 数字看着不对 | 把屏上出现的每个数字和事实表对一遍，列出不一致的。 |
